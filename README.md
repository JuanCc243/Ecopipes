# EcoPipes: Misión Lago de Maracaibo 🚰

Videojuego web interactivo para la concientización sobre la gestión de residuos y saneamiento del lago.

Acompaña a Jota, un ingeniero sanitario de Maracaibo, y acomoda las tuberías para que el agua sucia llegue
a la planta de tratamiento y no al lago. 20 niveles en 4 mundos: aguas residuales, basura y cañadas,
temporada de lluvias, e industria y petróleo.

## Jugar
- Juego normal: abrir el enlace de GitHub Pages de este repositorio.
- **Modo profesor** (todos los niveles desbloqueados y botón «Resolver»): agregar `#profesor` al final del enlace.
